Para finalizar

  • En un programa CRUD, los métodos Mostrar, Agregar, Modificar y Eliminar se repiten en todas las clases.
  • Los pasos generales del programa CRUD son:
    • Establecer la conexión a la base de datos con new mysqli(“localhost”,“root”, “”,“biblioteca”).
    • Crear el objeto de la clase
    • Llamar a algún método:
      • dentro del código se escribe la consulta SQL (SELECT / INSERT / UPDATE / DELETE)
      • se ejecuta el SQL con query($consulta)
      • se verifica si la consulta se pudo ejecutar $resultado=$conexion->query($consulta), para eso se evalúa la variable $resultado
      • if($resultado), verifica si la variable resultado no es falsa, eso sucede cuando falla la ejecución de la consulta.
  • Debe ejecutar el programa y probar las diferentes opciones para tener mayor claridad del código.
