Interactuando con la Base de Datos

Las consultas se ejecutan principalmente dentro de los métodos de las clases, como se observa en autor.php.

Los métodos (como Agregar, Mostrar, Modificar y Eliminar) reciben como parámetro el objeto de la conexión.

Para ejecutar una acción, escribimos la instrucción SQL entre comillas y llamamos al método query():

Ejemplo: $consulta="SELECT * FROM autor";

$resultado = $conexion->query($consulta);

query es un método que permite ejecutar una consulta SQL directamente en la Base de Datos

Las consultas SQL, estudiadas en 4° año, pueden ser SELECT, INSERT, UPDATE o DELETE.

En la variable $resultado se guarda el resultado de ejecutar el SQL.

  • Si es un SELECT la variable $resultado guarda un objeto con las referencias a cada fila de la tabla.
  • Si es una instrucción INSERT, UPDATE o DELETE, la variable $resultado recibe true o false
  • Si hay error al ejecutar el SQL, ese error se puede mostrar usando $conexion->error.
